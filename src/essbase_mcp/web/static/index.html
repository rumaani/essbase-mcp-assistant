How settings are stored

Saved to data/settings.json on the server and used on every restart. Secrets are encrypted with a key in data/secret.key (or EMCP_SECRET_KEY) and never sent back to the browser. Leave a secret blank to keep the saved one. Set EMCP_ADMIN_PASSWORD to protect this tab.
